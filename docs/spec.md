## 0. 用語

|用語|定義|
|---|---|
|對局時間|從倒數結束那一刻起算的毫秒數（`TimeMs`），所有規則都以它判斷，不讀系統時間|
|能量|每位玩家各自的整數資源，用來下子|
|回能進度|累積到回能間隔 `T` 時，能量 +1|
|請求|玩家想做的動作（下子、使用技能），可能被接受或拒絕|
|主機（Host）|區網對戰中開房的一方，唯一有權判定請求結果|
|黑方 / 白方|兩位玩家。人機對戰時玩家為黑方；區網對戰時主機為黑方|

## 1. 範圍

### 1.1 遊戲模式

- **M1** 人機對戰：一位玩家對 AI。
- **M2** 區網對戰：兩台電腦透過區域網路連線，一方開房、一方輸入 IP 加入。
- **M3** 開發用本機模式：同一台電腦，滑鼠左鍵下黑子、右鍵下白子。只供手動測試，不必做得精緻；為了方便除錯，此模式的 HUD 可以同時顯示雙方資訊（`E5` 的例外）。

### 1.2 非目標（v1 不做）

- 網際網路連線、配對、排行榜
- 禁手規則（即時制沒有先手優勢，故不設禁手）
- 重播、存檔
- 三人以上對局

---

## 2. 對局流程

- **G1** 開局前由主機（人機模式則為玩家）設定：回能間隔 `T`、AI 難度（僅 M1）。介面只提供合法的 `T` 值（見 §4）。區網對戰時主機在開房前設定，之後不能更改。
- **G1a** 設定完成後進入技能選擇階段，每位玩家各選一項技能（見 `S1`）。
    - 尚未選技能時不能按「確定」；按下確定後再選技能的請求一律忽略。
- **G2** 雙方都選好技能後顯示 3 秒倒數，倒數結束時對局時間 = 0，開始接受請求。倒數期間對局時間為負值：倒數開始時為 −3000，到 0 時進入對局。
- **G3** 技能選擇階段、倒數期間與對局結束後，所有下子與使用技能的請求一律以 `GAME_NOT_RUNNING` 拒絕。
- **G4** 對局結束後顯示結果畫面，提供「再來一局」與「回主選單」。再來一局時保留原設定，所有狀態重置，並回到技能選擇階段（預設選中上一局的技能，可以更換）。
    - 區網對戰：雙方都按「再來一局」才回到技能選擇；任一方按「回主選單」即斷線，另一方顯示「對手已離開」。

## 3. 棋盤

- **B1** 棋盤為 15×15，座標 `(x, y)`，`x`、`y` 皆為 0–14，`(0, 0)` 在左上角。
- **B2** 每格為「空」、「黑」、「白」三種狀態之一。
- **B3** 座標超出範圍的請求以 `OUT_OF_BOARD` 拒絕。

## 4. 能量

|參數|值|
|---|---|
|能量上限 `E_max`|10|
|開局能量|1|
|回能間隔 `T`|預設 2000 ms；可設定範圍 500–10000 ms，必須是 500 的倍數（即 0.5 秒、1 秒、1.5 秒…10 秒）|

- **E1** 能量為 0 到 `E_max` 的整數。
- **E2** 能量低於上限時，回能進度每經過 1 ms 增加 1（加速技能生效期間為 2，見 `SA2`）。
- **E3** 回能進度 ≥ `T` 時，能量 +1，進度扣掉 `T`。若一次經過的時間很長，要一次補足所有應回的格數（不能因為 tick 間隔大就少算）。
- **E4** 能量達到上限時，回能進度歸零並停止累積；之後一旦能量低於上限，從 0 重新開始累積。
- **E5** 每位玩家只能看到自己的能量、回能進度、下子間隔與技能冷卻；對手的這些資訊不公開（HUD 不顯示，AI 也不可讀取，區網連線也不傳給對方）。棋盤對雙方都公開。
- **E6** HUD 用一條分成 10 格的能量條，顯示自己的能量與回能進度，不顯示秒數：
    - 由左到右，前 `能量` 格為填滿。
    - 下一格（第 `能量 + 1` 格）依「回能進度 ÷ `T`」的比例部分填滿，隨時間連續往右長；長滿時變成填滿的一格，再從下一格開始累積。
    - 下子消耗能量時，填滿的格數少 1 格，正在累積的那一格跟著往左移一格，進度不變。
    - 能量已滿時，10 格全部填滿，不顯示累積中的格子。
    - 加速期間不另外計算，回能進度本來就變快，所以累積中的格子自然長得比較快。可以額外改變顏色，讓玩家看得出正在加速

## 5. 下子

|參數|值|
|---|---|
|每子消耗|1 格能量|
|下子間隔|1000 ms（同一位玩家兩次成功下子之間）|

- **P1** 下子請求依下列順序檢查，遇到第一個不符合的就拒絕並回傳該原因：
    1. 對局進行中，否則 `GAME_NOT_RUNNING`
    2. 座標在棋盤內，否則 `OUT_OF_BOARD`
    3. 該格為空，否則 `OCCUPIED`
    4. 距離自己上一次成功下子 ≥ 1000 ms，否則 `PLACE_COOLDOWN`
    5. 能量 ≥ 1，否則 `NO_ENERGY`
- **P2** 請求被接受時：該格放上自己的棋子、能量 −1、記錄本次下子時間。
- **P3** 被拒絕的請求不改變任何狀態（不扣能量，也不重設下子間隔）。
- **P4** 開局後第一次下子不受下子間隔限制。
- **P5** 兩位玩家幾乎同時下在同一格時，主機先處理到的成功，另一個以 `OCCUPIED` 拒絕。
- **P6** 被拒絕時，介面要給提示（例如該格閃一下紅色，或 HUD 顯示原因）。

## 6. 勝負

- **W1** 某玩家下子後，若該子所在的橫、直、兩條斜線中任一方向有連續 5 顆以上的己方棋子，該玩家立即獲勝，對局結束。
- **W2** 連 6 顆以上（長連）也算獲勝
- **W3** 只有「下子」會觸發勝負判斷；炸彈移除棋子不會讓任何人獲勝。
- **W4** 棋盤下滿且無人獲勝時，判定和局。
- **W5** 區網對戰中斷線時，對局中止，不計勝負（見 `N6`）

## 7. 技能

### 7.1 共通規則

- **S1** v1 共有兩個技能：「加速」與「炸彈」。每位玩家在開局前**選擇其中一項**，整局只能使用這一項，對局中不能更換。
    - 雙方可以選同一項技能。
    - 選擇階段沒有時間限制，雙方都按下「確定」後才開始倒數。
    - 開局前看不到對手選了什麼；對手第一次使用技能時才會知道：介面顯示「對手使用了○○」，之後持續可見。只揭露技能名稱，不揭露冷卻（`E5`）。
- **S1a** 使用自己沒選的技能時，以 `SKILL_NOT_OWNED` 拒絕。
- **S2** 使用技能不消耗能量
- **S3** 技能有冷卻時間，冷卻中使用時以 `SKILL_COOLDOWN` 拒絕。對局時間 ≥ 冷卻結束時間即可使用（剛好到期那一刻可用）。
- **S4** 開局時技能處於冷卻中，需等待一次完整冷卻才能使用
- **S5** 使用技能不受下子間隔影響，也不會重設下子間隔。
- **S6** 技能成功使用時，冷卻從使用那一刻重新開始計算。

### 7.2 加速（Accelerate）

| 參數   | 值        |
| ---- | -------- |
| 冷卻   | 25000 ms |
| 持續時間 | 5000 ms  |

- **SA1** 使用後，接下來 5000 ms（上表的持續時間）內處於加速狀態。
- **SA2** 加速期間回能進度累積速度為 2 倍（等同回能間隔減半）。
- **SA3** 加速不可疊加（冷卻比持續時間長，所以正常情況下不會發生）。
- **SA4** 能量已滿時仍可使用，只是沒有效果（回能進度仍依 `E4` 停止）。
- **SA5** 加速請求的檢查順序：`GAME_NOT_RUNNING` → `SKILL_NOT_OWNED` → `SKILL_COOLDOWN`。加速請求若帶有目標座標，忽略之。

### 7.3 炸彈（Bomb）

|參數|值|
|---|---|
|冷卻|20000 ms|

- **SB1** 使用時須指定一個目標座標。
- **SB2** 目標必須是對手的棋子；若為空格或自己的棋子，以 `INVALID_TARGET` 拒絕；若超出棋盤，以 `OUT_OF_BOARD` 拒絕。
- **SB3** 成功時，目標格變回空格，任何一方都可以立刻再下在該格。
- **SB4** 炸彈請求的檢查順序：`GAME_NOT_RUNNING` → `SKILL_NOT_OWNED` → `OUT_OF_BOARD` → `SKILL_COOLDOWN` → `INVALID_TARGET`。
- **SB5** 炸彈請求沒有指定目標時，在 `OUT_OF_BOARD` 那一步以 `INVALID_TARGET` 拒絕。

## 8. AI（人機模式）

### 8.1 行為限制

- **A1** AI 必須遵守和玩家完全相同的規則（能量、下子間隔、技能冷卻），並透過一般請求來行動，不能直接修改棋盤。
- **A2** AI 每次做完決策後，要等「反應時間」過去才能做下一次決策。
    - 判斷結果為「不行動」也算一次決策。
    - 對局開始（時間 0）時立即做第一次決策。
    - 難度只影響反應時間，其他參數（如 `w`）各難度相同。

|難度|反應時間|
|---|---|
|簡單|1200 ms|
|普通|700 ms|
|困難|350 ms|

- **A2a** AI 在技能選擇階段隨機選一項技能，亂數使用與 `A11` 相同、可指定種子的產生器

- **A3** AI 只能讀取棋盤與自己的狀態（能量、下子間隔、技能冷卻），不能讀取對手的能量與冷卻（`E5`）。


### 8.2 棋型定義（判斷某一方向時使用）

|棋型|定義|
|---|---|
|連五|同一方向連續 5 顆以上己方棋子|
|活四|4 顆連續己方棋子，兩端都是空格（有 2 個成五點）|
|衝四|再下一子就能成五，但只有 1 個成五點（含 `●●_●●` 這類中間有空格的形）|
|活三|再下一子就能變成活四的三子形（含 `_●●_●_` 跳三）|
|眠三|再下一子最多只能變成衝四的三子形|
|活二|再下一子就能變成活三的兩子形|
|眠二|再下一子最多只能變成眠三的兩子形|

判斷時，棋盤邊界與對手棋子都視為擋住。棋型以「假設該方下在某空格後」判斷；同一方向同時符合多種棋型時，取最強的一種。

### 8.3 決策優先順序

每次決策依序檢查，第一個成立的就執行：

- **A4** 自己下一子就能成五 → 下在那裡。
- **A5** 對手有成五點（對手有活四或衝四）：
    - 只有 1 個成五點，而且自己能下子 → 擋在那裡。
    - 有 2 個以上成五點（擋不完）：
        - 自己選的是炸彈且冷卻已好 → 炸掉對手威脅棋型裡的一顆子（選炸掉後對手威脅分降最多的那顆）。
        - 否則，若自己能下子 → 擋其中一個成五點（選擋下後對手威脅分降最多的那個；同分時選對自己評分較高的）。對手不一定有足夠的能量馬上補下另一個點，所以不能放棄。
    - 自己不能下子（能量不足或下子間隔未過）時，若自己選的是炸彈且冷卻已好 → 炸掉對手威脅棋型裡的一顆子；否則本次不行動。
    - 名詞：「成五點」是對手下一子就能成五的空格。「威脅分」先比對手成五點的數量，數量相同再比對手在全盤空格中的最高進攻分（`A10`），兩者都越小越好。「威脅棋型裡的子」是與某個成五點在同一條線上、能和它共同構成連五的對手棋子。
- **A6** 自己下一子能形成活四 → 下在那裡。
- **A7** 對手有活三 → 擋住它。候選擋點是能讓該棋型不再是活三的空格（兩端端點，以及跳三中間的空格）；對手有多個活三時，所有候選一起比較，選對自己評分（`A10`）最高的一格。
- **A8** 自己選的是加速、冷卻已好，且能量 ≤ 3 → 使用加速。
- **A9** 其他情況 → 依 `A10` 對所有空格評分，下在最高分的位置。
- 以上任何「下子」動作，若當下能量不足或下子間隔未過，本次就不行動，等下次決策再重新判斷。

### 8.4 評分

- **A10** 對每個空格：
    - 進攻分 = 假設自己下在這裡，四個方向形成的棋型分數總和。
    - 防守分 = 假設對手下在這裡，四個方向形成的棋型分數總和。
    - 總分 = 進攻分 + 防守分 × `w`，`w` 預設 0.8
    - 同一格在兩個以上方向形成活三或更強的棋型時（例如雙活三；「活三或更強」指活三、衝四、活四、連五），額外加上「雙活三」分數。進攻與防守各自判斷，防守那份的加成同樣乘以 `w`。

|棋型|分數|
|---|---|
|連五|100000|
|活四|10000|
|雙活三（加成）|8000|
|衝四 / 活三|1000|
|眠三 / 活二|100|
|眠二|10|

- **A11** 最高分有多格同分時，隨機挑一格。亂數產生器可以指定種子，以便測試結果可重現。
- **A12** 棋盤全空時下在中央 `(7, 7)`。

## 9. 區網連線

- **N1** 開房方監聽 TCP 埠 50505 ，加入方輸入主機 IP 連線。一個房間只接受一位對手。
- **N2** 主機是唯一的權威：雙方的請求（包括主機自己的）都交給主機的 GameController 判定。
- **N3** 加入方送出請求後不先自行改畫面，等主機回傳結果後再更新。
- **N4** 主機在每次狀態改變時，以及對局中每 200 ms，送出狀態快照給加入方。快照只包含棋盤、對局狀態與加入方自己的玩家狀態，不包含主機方的能量與冷卻（`E5`）。
- **N5** 主機與加入方的協定版本號（整數常數，與程式發行版本分開）不同時，拒絕連線並顯示提示。
- **N6** 雙方每 1000 ms 互送心跳；超過 5000 ms 沒收到任何訊息就視為斷線，對局中止，雙方顯示「連線中斷」。
- **N7** 回能間隔等設定由主機決定，在連線時傳給加入方。

## 10. 介面

- **U1** 棋盤：顯示 15×15 格線與棋子，點擊空格送出下子請求。
- **U2** HUD：只顯示自己的資訊，包括能量條（`E6`）、下子間隔是否已過、自己所選技能的按鈕與剩餘冷卻秒數、加速剩餘時間（選加速時）。不顯示對手的能量與冷卻（`E5`）。
- **U3** 使用炸彈（選炸彈時）：按下技能按鈕（或快捷鍵）後進入選擇目標狀態，點擊對手棋子即送出；按右鍵或 Esc 取消。
- **U4** 快捷鍵：`Q` 使用自己的技能
- **U5** 被拒絕的請求依 `P6` 給提示。
- **U6** 結束畫面顯示勝方或和局，並標出連成五的棋子：長連時標出整條連線；一子同時在多個方向成五時，所有連線一起標出。
- **U7** 技能選擇畫面：顯示兩項技能的名稱、效果說明與冷卻時間，點選後按「確定」。區網對戰時要顯示「等待對手選擇」。

## 11. 驗收方式

- 第 3–7 章每條規則都要有對應的自動化測試（GoogleTest），測試名稱要包含規則編號，例如 `EnergyTest.E3_CatchUpAfterLongGap`。
- 第 8 章：棋型判斷與評分要有單元測試；另外要跑「AI 對 AI」測試，連續對局 100 場不能出現任何被拒絕以外的錯誤，而且每場都要結束（每場模擬對局時間上限 30 分鐘，超過即算失敗）。
- 第 9–10 章：在 `docs/tasks.md` 的手動測試清單逐項確認。
