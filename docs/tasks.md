## 手動測試清單

### A　本機（T14）

- [ ] 開局前出現技能選擇畫面，選好按確定後才開始倒數
- [ ] 倒數 3 秒後才能下子
- [ ] 能量條回能速度與設定的間隔相符
- [ ] 能量條累積中的那一格平順往右長，長滿時變成完整一格
- [ ] 下子後少一格，正在累積的格子進度沒有被清掉
- [ ] 滿格時 10 格全滿；加速期間累積明顯變快
- [ ] 1 秒內連點兩次，第二次閃紅且不扣能量
- [ ] 能量 0 時點擊被拒並有提示
- [ ] 選加速：HUD 只有加速按鈕；加速期間能量條明顯變快，5 秒後恢復
- [ ] 選炸彈：HUD 只有炸彈按鈕；選目標模式、點對手棋子成功、點自己的棋子被拒、Esc 取消
- [ ] 再來一局回到技能選擇，預設選中上一局的技能
- [ ] 連五後顯示結果、標出連線，再來一局後全部重置

### B　人機（T18）

- [ ] 三種難度的出手速度明顯不同
- [ ] 做出活四時 AI 會擋；AI 選炸彈時會用炸彈解圍
- [ ] AI 不會違反下子間隔或能量限制

### C　區網（T22）

- [ ] 兩台電腦能連線，加入方看到主機設定的回能間隔
- [ ] 雙方畫面都只看得到自己的能量與技能冷卻，看不到對方的
- [ ] 技能選擇時，一方確定後另一方顯示「對手已準備」，但看不到對手選了什麼
- [ ] 雙方同時搶同一格，只有一方成功
- [ ] 拔掉網路線（或關掉一方程式），5 秒內雙方都顯示連線中斷
- [ ] 版本號不同時拒絕連線
